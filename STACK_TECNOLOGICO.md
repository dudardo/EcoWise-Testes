# Stack Tecnológico - EcoWise

O projeto EcoWise foi desenvolvido utilizando **Python 3.12** como linguagem principal do backend, executado através do microframework **Flask 2.x** para roteamento, sessões e renderização de templates via **Jinja2**; a persistência de dados é realizada em **SQLite** (arquivo `ecowise.db`) gerenciado pela ORM **SQLAlchemy** (Flask-SQLAlchemy), que abstrai o acesso ao banco e define modelos relacionais (`Usuario`, `DesafioConcluido`); a segurança é garantida por **Werkzeug** (hashing de senhas com PBKDF2); o frontend utiliza **HTML5** semântico, **CSS3** (arquivo único `EcoC.css` com Google Fonts - Poppins), e **JavaScript ES6+** vanilla com **Fetch API** para comunicação assíncrona com o backend (sem jQuery ou Axios); a integração é realizada através de micro-APIs REST (GET/POST `/api/desafios`) que implementam padrões como debouncing (600ms) e localStorage como fallback; recursos estáticos são servidos via `url_for()` em `static/`, enquanto PDFs residem em `/Ecoartigos/` e são servidos através de rota customizada com `send_from_directory()` para segurança; o código-fonte é versionado em **Git** no repositório **GitHub** (dudardo/EcoWise-Testes, branch main) com commits correlacionados a features; o desenvolvimento ocorreu em **VS Code Codespaces** (ambiente Ubuntu 24.04 em container) com hot-reload automático em modo debug; dependências gerenciadas via **pip** (`Flask==2.3.x`, `Flask-SQLAlchemy==3.0.x`, `Werkzeug==2.3.x`); não há dependências externas pesadas — a arquitetura prioriza simplicidade, modularidade e facilidade de manutenção para uma plataforma educacional.
